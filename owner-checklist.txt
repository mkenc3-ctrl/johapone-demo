# ════════════════════════════════════════════════════════════
#  이 파일은 사장님(이상호)이 직접 쓰는 곳입니다.
#  다른 사람이나 AI(Claude)가 쓴 글을 옮겨 넣지 마세요.
#  여기 쓴 내용이 체크리스트 각 단계 아래 「현장 실무 메모」 상자로 나옵니다.
#
#  ■ 쓰는 법
#   1. 아래 [ ] 제목 바로 밑에 줄을 추가합니다. 빈 단계는 화면에 아무것도 안 나옵니다.
#   2. 줄 맨 앞 기호로 종류를 나눕니다.
#        -  할 일        (예: - 동의서 받기 전 등기부 소유자와 명부를 한 번 더 맞춘다)
#        !  현장 주의    (예: ! 공유 지분은 대표자 선임 동의서를 따로 받는다)
#        *  실무 요령    (예: * 어르신 댁은 오전 방문이 서명받기 쉽다)
#   3. '#'으로 시작하는 줄은 설명이라 화면에 안 나옵니다.
#   4. 저장은 Ctrl+S. (메모장에서 「다른 이름으로 저장」할 때는 인코딩을 UTF-8로)
#   5. 다 쓰면 Claude에게 「체크리스트 메모 올려줘」라고 하면 공개 사이트에 반영됩니다.
#
#  ■ 저작권 관련
#   - 저장할 때마다 날짜가 남습니다. 올릴 때마다 공개 저장소에도 날짜 기록이 남습니다.
#   - 나중에 새 판을 저작권 등록할 때 「사장님이 직접 쓴 부분」의 증빙이 됩니다.
#   - [ ] 안의 영문·숫자(c1, s5a 등)는 지우거나 고치지 마세요. 단계를 찾는 표시입니다.
#   - 재건축 기준 단계 이름이지만, 재개발·가로주택 등 같은 단계에도 함께 나옵니다.
# ════════════════════════════════════════════════════════════
