내부 테스트용 시안 · 앱스토어 설치 없이 휴대폰 홈 화면에 추가해 사용합니다

① 휴대폰으로 열기

휴대폰 카메라로 QR코드를 찍거나, 카톡으로 받은 링크를 누르세요.

지금 열기

🤖 갤럭시 (안드로이드)

  1. 링크를 크롬 또는 삼성 인터넷으로 엽니다
    카톡 안에서 열렸다면 오른쪽 위 ⋮ → 다른 브라우저로 열기
  2. 오른쪽 위 ⋮ 또는 아래 ≡ 메뉴
  3. 홈 화면에 추가 또는 앱 설치
  4. 바탕화면의 조합ONE 아이콘으로 실행

🍎 아이폰

  1. 링크를 사파리로 엽니다
    카톡 안에서 열렸다면 오른쪽 아래 ⋯ → Safari로 열기
  2. 아래 가운데 공유 ⬆ 버튼
  3. 홈 화면에 추가 → 추가
  4. 바탕화면의 조합ONE 아이콘으로 실행

② 테스트 계정 (로그인 화면에서 선택)

계정테스트할 것
홍길동 (조합원·글쓰기 허가)전자동의서 서명 제출, 전자투표, 온라인총회 입장, 모임방 글쓰기
홍순자 (조합원·일반)모임방 글쓰기 권한 신청, 정보공개 확인
박정수 (조합장)동의·투표 집계, 정보공개 등록, 명부관리, 권한 승인
김주무관 (구청 담당자)관할 조합 점검, 자료 열람
⚠️ 꼭 지켜주세요 실제 조합원 명부·신분증·연락처 등 개인정보는 절대 입력하거나 올리지 마세요. 이 시안은 테스트용이며, 입력한 투표·글·첨부파일은 공유 테스트 서버에 저장되어 다른 테스트 참가자에게도 보입니다. (엑셀로 불러온 명부만 예외로 그 기기 안에서만 처리됩니다.)

③ 영업 시연 시나리오

시·구 담당자 → 조합장 → 조합원 순서로 약 10분 시연합니다. PC에서는 설명과 실제 화면이 나란히 보이고, 휴대폰에서는 단계별 「이 화면 열기」로 진행합니다.

시연 전용 조합(OO3구역)을 사용하므로 테스트 데이터와 섞이지 않습니다. 시연 직전에 「🔄 시연 전 데이터 초기화」를 한 번 누르세요.
